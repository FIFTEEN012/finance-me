# Small, hand-written Move library

The Move library is about 30 hand-written Moves (bodyweight and dumbbell, no images), each citing a reputable source (ACE, NSCA, NHS) and reviewed by the owner before merge. Moves are not generated by AI at runtime, because a wrong instruction on form can injure someone and fixed data can be tested.

An earlier exercise library (commit 20957e9: a ~73,000-line `exercises.json`, a workout generator wizard, routines and gamification) was removed in fd015d1 because it was too heavy and too complex for how the app was used. Grow this library slowly and keep named routines out unless usage shows they are needed.
