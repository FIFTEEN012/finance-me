# Every exercise log is a Workout Session

Every logged exercise is a Workout Session of one Session Type; a list of Moves is optional. Calories burned come from the Session Type's MET × body weight × minutes, not from a MET per Move.

We chose one concept over a separate "strength workout" record so weekly minutes, the 7-day chart and the exercise-adjusted calorie and water targets keep working unchanged. Per-Move MET values would look more precise without being meaningfully more accurate, and would be costly to maintain.
